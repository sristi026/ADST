# Case Study 01: Food Delivery System

## 📌 Problem Statement
Develop a Food Delivery System that analyzes customer orders, restaurant performance, delivery conditions, and payment factors to determine order acceptance, rejection, priority handling, and final payable amount.

The system uses customer details, order amount, distance, ratings, weather conditions, demand level, and cancellation history to generate an intelligent order decision report.

---

## 🎯 Objectives
- Calculate delivery charges based on distance and weather conditions.
- Apply discounts according to customer type and order value.
- Identify priority orders based on customer and demand factors.
- Analyze cancellation risk.
- Detect orders requiring manual verification.
- Generate final order status and payable amount.

---

## 🛠️ Technologies Used
- Python
- Conditional Statements
- User Input Handling
- Logical Decision Making

---

## ⚙️ Features
- Restaurant rating classification
  - Excellent
  - Good
  - Average
  - Poor

- Dynamic delivery charge calculation
- Customer-based discount system
- Priority order detection
- Cancellation risk analysis
- Manual review verification
- Order acceptance/rejection decision
- Final billing calculation

---

## 📊 Input Parameters
The system takes the following inputs:

- Order Amount
- Delivery Distance
- Customer Type
- Customer Rating
- Restaurant Rating
- Preparation Time
- Payment Method
- Weather Condition
- Demand Level
- Peak Hour Status
- Previous Cancellations

---

## 🚀 How It Works

1. User enters order and customer details.
2. System evaluates restaurant and customer ratings.
3. Delivery charges and discounts are calculated.
4. Risk factors are analyzed.
5. Order is classified as:
   - Accepted
   - Rejected
   - Manual Review

6. Final order report is generated.
